Reference actions · Research candidates

Fast local fits still fail complete placement

9 November 2026 · DVIDIA

Fast predictions still need precise, complete actions.

Two CPU fits · 0/4 placements per model · unqualified

Inspect all eight recorded attempts ↗ · Source & history · Download Markdown

Study abstract and scope

Abstract

Two compact PiPER endpoint models train on the same 96,000 demonstrated action samples in 5.231 and 5.098 seconds. Saved-model recorded-context outputs match exactly. A separate eight-attempt native development experiment yields zero strict placements for both absolute and reference-relative decoders. Absolute control reaches one lift; relative control reaches none and records more critical contacts. All outcomes and sixteen earlier infrastructure refusals are retained. This engineering follow-up establishes a usable local learning and evaluation bridge, not a qualified skill, unseen-start superiority or ordinary video-to-action transfer.

Two small PiPER controllers each trained on 96,000 demonstrated action samples in about five seconds on a local CPU. Both then failed all four scheduled placement attempts. Fast fitting and accurate recorded-action prediction have not yet produced a reliable downloadable skill.

This is a separate engineering follow-up to the camera-to-action study. It leaves that study's frozen 5/64 result and failed qualification unchanged. The new candidates remain simulation-only, unqualified research models.

What changed

The original learner predicts joint and gripper targets. This follow-up learns an endpoint consistent with the actuator's existing rate limits. It compares an absolute endpoint with an endpoint relative to the preceding applied servo reference. Both use the same 269 causal features, two 64-unit hidden layers, initial weights, training data, optimizer budget and actuator constraints.

The preceding reference is stored as float64. It is the reference actually applied to the servo, not a measured joint position or the teacher's next command. In correction recordings, teacher suggestions remain distinct from executed commands. Initial visual position is explicitly historical; unavailable current observations keep their masks and ages. No teacher phase, current teacher command, native object/contact truth or future frame enters the policy.

For network output g, reset reference r₀, preceding reference r, and per-command scale D, the decoders are r₀ + Dg and r + Dg. The common scale is 0.03 rad for each arm joint and 0.001 m for one gripper finger. Both optimize the same physically scaled, unprojected endpoint loss. At execution they use the original bounds and exact twenty 1 ms reference updates. These limit commands; they do not guarantee safe contact or bound actual joint motion.

Source and API retain a separate model schema. The existing installer does not yet accept this format. Neither model is a hardware controller or a qualified skill.

Training and recorded-context checks

Exactly two real fits used the same 64 teacher and 32 mixed-control training recordings, covering 32 starting-position groups. Each fit used seed 17, 50 epochs, batch size 512 and Adam learning rate 0.003. Normalization used training data only. No development or confirmation recording entered fitting.

Eight actual control attempts

A separate, fixed engineering roster used the first two original development starting positions, each with both destinations and both retained models. These are reused development scenes, not fresh confirmation. There was no teacher intervention, fallback, model selection, tuning or replacement of a failed case.

All eight attempts completed 20 simulated seconds: 8,000 motor intervals, 4,008 RGB-D pairs and 160,000 native physics ticks in total. Independent readback verified the saved inventories and recomputed native scores without running physics or model inference.

A grasp flag is not a completed test lift or a secure transported object. Native metric consistency passed for all eight recordings, while all four relative trajectories also failed the strict trajectory contract with invalid_state_value: finite tool coordinates crossed its fixed ±0.5 m component envelope. The first rejected components were x=0.501866 m, x=0.503337 m, z=0.504985 m and x=0.500157 m, in relative-model roster order. These were not NaNs or physics warnings. Outer native consistency does not override a strict trajectory failure; no score was relaxed to make them pass.

Inspect every attempt using actual camera frames, measured joints, issued commands, applied references and observation availability. The viewer includes all eight attempts in registered order. It displays RGB at 2.5 Hz from the original 25 Hz capture and retains all 50 Hz decisions. Its independent readback binds the displayed evidence. This small comparison has no fixed or blind comparator and does not establish superiority, a population success rate or hardware performance.

Failures before the control experiment

Two earlier eight-attempt batches stopped before any learned control. The first was blocked by a subprocess guard rejecting MuJoCo's read-only macOS startup check. The second passed that check but could not create a CoreGraphics context inside the default execution sandbox. All sixteen refusals remain retained.

A separate static 48×64 frame check reproduced the graphics refusal and then succeeded with scoped graphics access. The final eight-attempt batch used the same source, weights, scenes, physics, scorer and resource guards as the second batch, with the corrected execution access. No failed evidence was overwritten. The renderer also warned that ARB_clip_control was unavailable with the requested depth mode. Its stated depth-accuracy limitation remains a limitation; we have not established that it caused the task failures.

Where the actions diverge

Comparing the eight saved attempts with four teacher recordings from exactly the same development starts isolates two gaps. The teachers achieved sustained lift by 11.836–12.056 seconds. The strongest absolute candidate did not qualify its lift until 18.991 seconds; its finger reference began sustained closure 6.76 seconds later than the matching teacher. Another absolute attempt never closed below the diagnostic 30 mm threshold. Absolute joint tracking RMS was 0.0140–0.0200 rad versus 0.0197–0.0206 rad for the teachers, so missing progress is already present in the commands; this is not explained solely by the simulated actuators failing to follow them. All four relative candidates contacted the table with finger links before closing, at 7.344–7.574 seconds. Their first recorded critical-contact snapshots placed the tool 4.54–7.04 mm lower than the matched teacher. Millimetre-scale approach accuracy matters before grip waiting can help.

The next bounded experiment should test a short-horizon acquisition policy that learns tool-pose/gripper subgoals and completion progress through approach, closure and test lift, against the unchanged endpoint controller under matched data and correction budgets. Score contact-free approach, loaded grasp, sustained lift, stalls and false progress independently before adding transport. Any authored IK or progress scaffold must be disclosed, and teacher phase labels or native contact truth must remain outside evaluation inputs. This is a proposed experiment, not a demonstrated fix: the comparison reused saved development recordings without new fitting, model calls, teacher intervention or simulation, and it establishes no causal treatment effect or qualification.

Read the matched-teacher diagnostic. The proposed larger 164-attempt screen has not run, and no candidate has been promoted. The unchanged model files, cards and compact receipts are available in the GitHub benchmark.
