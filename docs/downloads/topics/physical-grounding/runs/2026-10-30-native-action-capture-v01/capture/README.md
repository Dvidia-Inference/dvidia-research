# DVIDIA · Recorded PiPER capture viewer

This small web derivative displays lossy RGB video and all saved boundary telemetry. It runs no physics and supplies no learned skill. Download the complete original capture kit, source preview wheel, PNG/NPY frames and audits from https://huggingface.co/datasets/Dvidia/piper-action-capture-v01 . The derivation receipt lists every original RGB input hash and probed video frame count. Depth precision is limited; object tracking is missing and strict training export remains refused.
