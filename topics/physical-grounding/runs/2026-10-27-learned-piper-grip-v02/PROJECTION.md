# DVIDIA learned grip v0.2 recorded projection

This directory contains the recorded browser replay, compact original metadata, diagnostic reports, and local-installation contract/wheel. It is not the complete 1.8 GB evidence dataset. Dense native arrays and all failed development/training attempts remain in the public Hugging Face dataset linked from the paper and replay. `experiment-integrity.json` is the original complete-study file manifest, not a claim that all those files are duplicated here. `viewer/viewer-integrity.json` seals the smaller recorded projection.

The current [browser-managed resource projection](viewer/BROWSER-MANAGED-RESOURCES.json) embeds the exact original gzip geometry and first recorded case in a browser-managed script, then loads the other saved cases as fixed SHA384-bound literal data resources. Each decoded payload retains its original hash. Native evidence links pin dataset revision `52cfbdabb550beee7af4e2af41e3e8c534c59baf`; the entry script URL also contains its exact content digest to avoid reusing the previous bundle. This changes no simulation, policy, score, pose or original geometry bytes.

The original viewer remains available in research commit `443b1f036bc705a23b3e5a67ccf43a14f7be6e38` and the sealed training run. Earlier hosting experiments remain preserved below; they are historical, not the current loader.
