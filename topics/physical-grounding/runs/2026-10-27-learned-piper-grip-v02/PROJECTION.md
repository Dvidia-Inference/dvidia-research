# DVIDIA learned grip v0.2 recorded projection

This directory contains the recorded browser replay, compact original metadata, diagnostic reports, and local-installation contract/wheel. It is not the complete 1.8 GB evidence dataset. Dense native arrays and all failed development/training attempts remain in the public Hugging Face dataset linked from the paper and replay. `experiment-integrity.json` is the original complete-study file manifest, not a claim that all those files are duplicated here. `viewer/viewer-integrity.json` seals the smaller recorded projection.

The viewer now uses a separate [geometry transport derivation](hosting-experiments/GEOMETRY-TRANSPORT.json): 26 individually verified small pieces reconstruct the exact original geometry. Its derived viewer seal records the unchanged parent seal. This responds to an observed initial public download timeout followed by a successful reload; it changes no simulation, policy, score, pose or original geometry bytes. The original viewer remains available in research commit 443b1f036bc705a23b3e5a67ccf43a14f7be6e38 and the sealed training run.

A later cold public load also timed out on a small geometry piece; chunking alone has not established a transport fix. A separate [transport diagnostic](hosting-experiments/TRANSPORT-DIAGNOSTICS.json) now exposes local request phase, HTTP status and byte progress in an expandable view and timeout message. This records no telemetry and changes no scientific evidence.

The observed stall was an HTTP200 binary body stopping partway through transfer. A further [text transport projection](hosting-experiments/TEXT-TRANSPORT.json) tests bounded canonical JSON/base64 envelopes for the same geometry and lazy poses, followed by every original decoded-byte/whole-geometry checksum and mesh-bound check. All original binary files remain unchanged. This is a transport hypothesis pending public browser verification.

Text envelope bodies also stalled in the controlled public test. A separate [native buffered-read compatibility experiment](hosting-experiments/NATIVE-BUFFERED-ENVELOPES.json) now tests the browser’s whole-response reader for known envelopes up to 1 MiB. Exact completed byte count and both SHA checks remain; its different precompletion memory behavior is explicit. This remains an unproven transport hypothesis until public verification.

The native buffered-read experiment also timed out after 120 seconds, with 22/26 geometry chunks available. The current [browser-managed resource projection](viewer/BROWSER-MANAGED-RESOURCES.json) embeds the exact original gzip geometry and first replay in a browser-managed script, then loads other saved cases as fixed SHA384-bound literal data resources. Every decoded byte retains its original hash. This distinct transport experiment is awaiting independent public validation; the failed transport notes above remain archived for review.
