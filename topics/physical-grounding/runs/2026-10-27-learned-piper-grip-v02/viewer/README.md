# PiPER learned feedback replay v0.2

Recorded synthetic PiPER learned-grip simulation. Only the jaw adapter is newly learned; all six arm commands remain the frozen v0.1 learned primitive. Native model geometry and saved states reconstructed with mj_forward only; no browser physics, live policy, human-video learning or physical robot qualification. The blind control is a separately trained learner without live feedback, not a shuffled-label model.

Serve the complete export over HTTP and open index.html. All rendering code and geometry are local. Playback does not rerun physics or inference. Frame metadata and pose binaries are per-case, hash-bound chunks loaded only for the selected replay. Every published file is at most 8 MiB. This is a viewer projection, not the full study bundle. All 120 original 20 ms episodes, scores, native metadata and receipts are local; dense 1 ms native NPZ arrays remain in the linked Hugging Face dataset and complete GitHub evidence archive. Original NPZ hashes are retained in motion.json and attempt receipts. Dataset links are configured without network verification; consult the final publication receipt for the verified commit and anonymous readback. The blind control is trained without live feedback; it is not a shuffled-label learner. Checksums establish artifact consistency, not authenticity. Three.js and PiPER notices are included.
